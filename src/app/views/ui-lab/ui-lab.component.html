19

Tokens y futura arquitectura

Variables experimentales locales. Todavía no es una librería definitiva.

Futuro estándar global
Tipografía, alturas, padding, bordes, radius, estados, gaps, comportamiento y accesibilidad.
Variable por sistema
Colores, identidad visual y logos. Cambie la paleta arriba para comparar.
Variable por formulario
Anchos, distribución, filas, columnas, agrupaciones y responsive específico.
Variable por dato / dominio
Validación, normalización, formato e información contextual: DV del RUT, fecha visual/API, hora y datos de país o programa.

Tokens locales: --ui-primary, --ui-primary-hover, --ui-primary-soft, --ui-surface, --ui-surface-soft, --ui-text, --ui-text-secondary, --ui-border, --ui-focus, --ui-success, --ui-warning, --ui-danger, --ui-disabled y --ui-readonly-bg. Navigation usa --nav-hover-bg, --nav-active-bg, --nav-active-indicator, --nav-icon, --nav-icon-hover y --nav-focus.

Densidad operacional: no adoptar automáticamente inputs de 48/56px, títulos enormes ni gaps amplios. UX guiada: indicar el dato esperado, ayudar con formatos, conservar errores y mantener clara la siguiente acción, sin llenar la pantalla de instrucciones.

A evaluar posteriormente: Angular Aria, Material/CDK, Signal Forms, CSS Custom Properties, SCSS, Vitest y eventualmente Storybook. Las herramientas aportan comportamiento y accesibilidad; nosotros definimos apariencia, densidad, geometría y distribución. Sin nuevas dependencias. Pendiente antes de estandarizar: contraste, disabled, foco, teclado, lector de pantalla, ARIA, área mínima de interacción, posicionamiento de overlays, zoom, responsive y reduced motion. No se declara cumplimiento total.
