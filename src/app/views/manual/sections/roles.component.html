Roles y Permisos

info
Los roles determinan qué funciones y acciones puede utilizar cada usuario dentro del sistema.

Dependiendo del rol asignado, algunas opciones pueden estar disponibles y otras permanecer restringidas.

Roles disponibles

admin_panel_settings
Administrador

Tiene acceso amplio al sistema y puede realizar tareas de administración, incluyendo la gestión de mantenedores y configuraciones disponibles.

supervisor_account
Supervisor

Puede revisar y gestionar demandas de acuerdo con los permisos asociados a su perfil.

badge
Administrativo

Puede registrar y gestionar demandas según las funciones habilitadas para su rol.

Rol y programa activo

Además del rol, el sistema considera el programa desde el cual está trabajando el usuario.

account_tree
Una demanda puede estar activa, pero eso no significa que todos los programas puedan realizar acciones sobre ella.

Si el programa del usuario mantiene una etapa abierta, podrá realizar las acciones correspondientes. Si la etapa de ese programa ya terminó, la demanda podrá quedar disponible solo para consulta.

Cambio de rol o programa

Cuando un usuario tiene más de un rol o programa disponible, debe verificar cuál se encuentra seleccionado antes de comenzar una gestión.

check_circle
Antes de gestionar una demanda: revise que el rol y el programa seleccionados correspondan al contexto en el que necesita trabajar.
