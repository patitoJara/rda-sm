Módulo de Referencia de Demandante entre Programas

info
El módulo de Referencia permite gestionar el traslado de un demandante desde un programa activo a otro dentro del sistema RDA-SM, asegurando trazabilidad, continuidad de atención y consistencia normativa.

Objetivo del módulo

La referencia está orientada a mantener la continuidad del proceso terapéutico cuando un usuario requiere cambiar de programa por razones clínicas, administrativas o territoriales.

verified
La referencia no elimina información previa. El registro clínico original mantiene su historial, y el programa destino asume la continuidad del proceso.

Flujo del proceso de referencia

  • Paso 1 – Buscar RUT: se ingresa el RUT del demandante. El sistema valida formato y existencia de registros asociados.
  • Paso 2 – Seleccionar Registro: si existen múltiples registros, el usuario selecciona el correspondiente al programa activo.
  • Paso 3 – Revisión Clínica: se muestra una ficha resumen con datos del postulante y del registro actual.
  • Paso 4 – Programa Destino: se selecciona el programa al cual será referenciado el demandante. El sistema excluye automáticamente el programa de origen.
  • Paso 5 – Confirmación: se muestra un resumen de la referencia incluyendo programa destino y lista de correos que serán notificados.
  • Paso 6 – Ejecución: el sistema confirma la operación y registra la referencia en la bitácora del demandante.

Notificación automática

mail
Al ejecutar la referencia, el sistema genera una notificación por correo electrónico a:
  • Profesionales asociados al programa de origen
  • Profesionales asociados al programa destino
  • Usuarios con rol Supervisor
  • Usuarios con rol Administrador

Esta notificación informa que el demandante ha sido referenciado, facilitando la coordinación clínica entre equipos.

Validaciones del sistema

warning
El sistema no permite ejecutar la referencia si:
  • No se ha seleccionado un programa destino.
  • El usuario no posee permisos suficientes.
  • El registro clínico no se encuentra vigente.

Seguridad y control

lock
El proceso mantiene trazabilidad institucional, registrando:
  • Usuario que ejecuta la referencia
  • Programa de origen
  • Programa destino
  • Fecha y hora del evento

Finalización del proceso

Una vez completada la referencia, el sistema muestra un mensaje de confirmación y permite reiniciar el módulo para realizar una nueva referencia si fuese necesario.

check_circle
La referencia es una acción clínica formal dentro del sistema y debe ser realizada únicamente cuando exista validación profesional o administrativa correspondiente.
