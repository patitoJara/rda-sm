# ARNÉS API

## Objetivo

Conservar el contrato REAL de las APIs utilizadas por el sistema.

## Por endpoint registrar

- método;
- ruta;
- parámetros;
- request si corresponde;
- respuesta real;
- campos relevantes;
- consumidores;
- reglas conocidas;
- observaciones.

## Reglas

- Una API se documenta una sola vez.
- Los formularios deben apuntar al arnés API correspondiente.
- No duplicar contratos API en distintos módulos.
- Registrar especialmente qué información DEVUELVE realmente la API.
- Si documentación y respuesta real difieren, verificar implementación
  y actualizar el arnés.
