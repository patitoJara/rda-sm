# ARNÉS UI

## Objetivo

Mantener el estándar visual reutilizable de los sistemas.

## El control base define

- altura;
- tipografía;
- tamaño de letra;
- padding;
- borde;
- radio;
- foco;
- error;
- disabled;
- comportamiento responsive.

## Regla principal

EL ANCHO NO PERTENECE AL CONTROL BASE.

El ancho pertenece al formulario y se define según:

- tipo de dato;
- longitud esperada;
- campos vecinos;
- espacio disponible;
- comportamiento desktop/tablet/mobile.

## Preferencia visual

- Controles compactos.
- Formularios limpios y densos.
- Evitar inputs y selects innecesariamente grandes.
- Mantener consistencia visual.
- Reutilizar patrones ya aprobados antes de diseñar otros nuevos.

## Responsive

Desktop:
- distribución compacta;
- aprovechar horizontalidad.

Tablet:
- redistribuir campos sin comprimirlos excesivamente.

Mobile:
- priorizar una columna;
- controles cómodos para interacción táctil.
